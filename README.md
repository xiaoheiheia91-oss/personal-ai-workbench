# Personal AI OS v2.0-alpha

当前阶段实现个人 AI OS 的最小闭环：

- 保存今日主线
- 快速捕获想法
- 将捕获转换为任务
- 标记任务完成
- 在首页查看任务统计和最近记录

## 数据存储

本阶段保持纯静态部署，数据由 `storage.js` 写入浏览器 `localStorage`。数据不会自动跨设备同步；后续版本会在不改变页面流程的前提下替换存储层。

## 本地与 Vercel 部署

这是一个无构建步骤的静态站点。将仓库部署到 Vercel 后即可运行，无需环境变量、数据库或服务器端密钥。

手动验收步骤见 `tests/manual-alpha-checklist.md`。
