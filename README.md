# Personal AI OS v2.0-alpha.3.5.2

Personal AI OS 是一个遵循 **Local First，AI Optional** 的纯静态个人工作台。今日任务、捕获箱、笔记、知识库、个人记忆、搜索、历史查看和 JSON 备份均不依赖 AI，也不需要外部网络。

## 当前能力

- 保存今日主线和每日复盘。
- 快速捕获想法，并转换为任务或笔记。
- 管理任务的今日标记、优先级、截止日期和生命周期状态。
- 创建、编辑、搜索、筛选、归档和恢复笔记。
- 查看捕获、任务、笔记、决策和复盘的历史状态。
- 在个人记忆中心搜索全部 Schema v3 记录。
- 导出包含版本元信息、数据统计和完整业务数据的 JSON 备份。
- 从本地 JSON 文件预览并安全恢复完整 Schema v3 备份，仅允许恢复到空数据空间。
- 提供面向未来 AI 增强层的只读上下文出口；当前不连接任何模型。

## 直接离线打开

项目没有构建步骤和第三方运行时依赖。在桌面浏览器中直接打开 `index.html` 即可使用：

1. 下载或克隆整个仓库，保持 HTML、CSS 和 JavaScript 文件在同一目录。
2. 双击 `index.html`，或在浏览器中选择“打开文件”。
3. 数据保存在当前浏览器针对该地址维护的 `localStorage` 中。

当前版本已在 Edge 的 `file://` 模式验证通过。不同浏览器对本地文件存储的处理可能不同；长期使用更推荐固定地址的本地 HTTP 模式。

## 局域网 HTTP 与手机访问

局域网方式需要电脑已有 Python 3 或其他可信的静态文件服务器；这只是页面分发工具，不是应用的运行时依赖。电脑和手机连接同一个可信 Wi-Fi 后：

1. 在电脑上运行 `ipconfig`，找到 WLAN 的 IPv4 地址，例如 `192.168.2.152`。
2. 运行 `py --version` 确认 Python 可用，然后在项目目录启动静态服务器。将示例地址替换为电脑的实际 WLAN 地址：

```powershell
py -m http.server 8000 --bind 192.168.2.152
```

如果没有 `py` 命令，可先运行 `python --version` 检查 `python` 命令，再尝试：

```powershell
python -m http.server 8000 --bind 192.168.2.152
```

如果两条版本检查都失败，需要先准备 Python 3 或等效的本地静态服务器；直接打开 `index.html` 不需要安装这些工具。

3. 在手机浏览器访问 `http://192.168.2.152:8000/`。
4. 使用结束后按 `Ctrl+C` 停止服务器。

只应在可信的专用网络中开放服务，不要配置公网端口转发。直接从仓库目录启动会同时暴露仓库中的其他文件；更安全的独立运行目录和防火墙说明见 [Local First 本地运行指南](LOCAL_FIRST.md)。

## 数据隔离

数据按“设备 + 浏览器 + origin”隔离。以下地址拥有互不相通的 `localStorage`：

- `file://.../index.html`
- `http://localhost:8000`
- `http://192.168.2.152:8000`
- Vercel 的 HTTPS 域名

更换浏览器、协议、域名、IP 或端口后，页面可能看起来像一套全新的数据。数据没有丢失在服务器上，也不会自动跨设备同步；它仍属于原来的浏览器 origin。

建议为每台设备选择一个长期固定的访问地址。局域网模式可使用固定的 DHCP 地址或稳定的局域网主机名，避免 origin 因 IP 变化而改变。

## JSON 备份建议

在“个人记忆”中使用“导出 JSON 备份”。备份包含：

- `exportFormatVersion`、`appVersion`、`schemaVersion` 和导出时间。
- 各类记录的数据统计。
- 完整、未改写的 Schema v3 业务数据。

建议至少在以下时间导出：

- 每周或完成重要阶段后。
- 清理浏览器数据、重装浏览器或更换设备前。
- 更换访问地址、端口或部署域名前。
- 升级 Personal AI OS 前。

将备份保存在至少两个由自己控制的位置。Alpha 3.5.2 可在“个人记忆”中选择该 JSON 文件，校验来源、创建时间和记录数量后恢复。为防止误覆盖，恢复只允许写入空数据空间，不会覆盖或自动合并已有记录。

## Vercel 与本地模式

同一套静态文件可以同时通过 Vercel、本地文件和局域网 HTTP 使用。Vercel 只分发页面资源，业务数据仍保存在访问设备的浏览器中，不会上传到项目服务器。

Vercel 页面首次加载或缓存失效时需要互联网；当前没有 Service Worker，不能把 Vercel 模式视为可靠的离线入口。无网络时请使用 `file://` 或局域网 HTTP 模式。

## 技术边界

- 原生 HTML、CSS、JavaScript。
- Schema v3 和浏览器 `localStorage`。
- 无构建步骤、无后端、无数据库、无第三方依赖。
- 无模型 API 请求、无 API Key、无 AI 运行依赖。
- 当前不支持自动同步；JSON 恢复仅支持完整 Schema v3 备份和空数据空间。

完整本地使用说明见 [LOCAL_FIRST.md](LOCAL_FIRST.md)，手动验收步骤见 `tests/manual-alpha-checklist.md`。
