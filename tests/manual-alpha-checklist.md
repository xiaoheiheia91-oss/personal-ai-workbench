# v2.0-alpha Phase 1 Manual Checklist

1. Open `index.html` or the deployed Vercel URL.
2. Save a daily goal, refresh the page, and verify the goal remains visible.
3. Save a capture with each available source and verify it appears in the capture inbox.
4. Convert an inbox capture to a task and verify the capture is marked as converted.
5. Mark the generated task as complete and verify its completed timestamp is displayed.
6. Refresh the page and verify captures and tasks remain unchanged.
7. Verify dashboard totals and recent records reflect each action.
8. Check the layout at a narrow mobile viewport and confirm there is no horizontal overflow.
